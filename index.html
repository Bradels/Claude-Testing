Process

How this site was made

The entire flow from idea to live website, driven entirely by conversation with Claude Code.

1

User sends a prompt

"Go and deploy the static page" — that's the starting point. No files, no boilerplate.

2

Claude creates a branch

A new Git branch is created in the connected repository to isolate the work.

3

Code is generated

HTML, CSS, and JavaScript are written from scratch — framework included, responsive and polished.

4

Commit & push

Changes are committed with a descriptive message and pushed to the remote branch.

5

Site goes live

GitHub Pages picks up the branch and the website is deployed — accessible to the world.
